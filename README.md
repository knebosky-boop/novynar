# Новинар

Стежить за телеграм-каналами і надсилає новини обраним людям
через бота **@Kate_news_2026_bot**.

## Як воно влаштоване

Канали зі списку — **відкриті**, у кожного є публічна веб-сторінка
(`t.me/s/tgp_news` — спробуйте в браузері). Програма щодві хвилини зазирає туди,
бачить нові пости й віддає їх ботові.

Вашого акаунта це не торкається зовсім: ні входу, ні пароля, ні ключів.
Працює лише бот. Якщо колись знадобиться **закритий** канал — тоді доведеться
вертатись до варіанта з акаунтом, він лежить поруч у `novynar_account.py`.

## Хто головний

Перший, хто натиснув **Start** у бота, став власником — це ви. Далі:

* друг відкриває `https://t.me/Kate_news_2026_bot` і тисне **Start**;
* бот пише вам: «стукав такий-то»;
* ви відповідаєте `/allow @його_юзернейм` — і він у потоці.

Чужі всередину не пройдуть.

## Команди в боті

| Команда | Хто | Що робить |
|---|---|---|
| `/status` | усі | стан, список каналів, скільки в черзі |
| `/digest` | усі | віддати накопичене просто зараз |
| `/stop` / `/start` | усі | вимкнути / увімкнути потік для себе |
| `/add @канал` | власниця | додати джерело |
| `/del @канал` | власниця | прибрати джерело |
| `/allow @людина` | власниця | впустити людину |
| `/deny @людина` | власниця | відрізати людину |
| `/pause`, `/resume` | власниця | зупинити / продовжити збір |

## Що відсіюється саме

* **Дублі** — та сама новина з п'яти каналів піде один раз (порівнюється текст,
  пам'ять 48 годин).
* **Реклама** — за стоп-словами зі `STOP_WORDS`. Шукає за основою слова:
  «реклама» зловить і «реклами», і «рекламний».
* **Дрібниця** — пости коротші за `MIN_LENGTH` символів без картинки.
* **Ніч** — перерви немає: новини йдуть цілодобово, як удень. Нагадування
  «є що почитати» лишаються о 08:00 і 20:00. Повернути нічну паузу —
  `QUIET_HOURS = (23, 8)` у `config.py`.
* **Лавина** — якщо канал вивалив 30 постів за раз, підуть останні 8.

## Якщо канал виправив новину

Пости на сторінці каналу живі: автор може їх переписати вже після того, як
новина пішла вам. Кожного обходу Новинар звіряє надіслані новини з тим, що
зараз у каналі.

* **Виправили суттєво** — текст у вашому повідомленні оновлюється на місці,
  а нижче приходить коротке «✏️ Канал виправив цю новину» відповіддю на неї.
* **Одрук чи кома** — текст оновлюється мовчки, без окремого повідомлення.
* **Новина розрослась** так, що вже не вміщається в ті самі повідомлення —
  виправлена версія приходить окремим повідомленням із позначкою «ВИПРАВЛЕНО».

Стежимо `EDIT_HOURS` годин після надсилання і лише поки пост видно на сторінці
каналу: у балакучих каналів це година-дві, у спокійних — кілька діб.

## Налаштування — файл `config.py`

| Що | Навіщо |
|---|---|
| `MODE` | `"instant"` — одразу; `"digest"` — зведеннями о годинах із `DIGEST_TIMES` |
| `QUIET_HOURS` | `None` — цілодобово; `(23, 8)` — нічна пауза до ранку |
| `KEYWORDS` | якщо заповнити — пройде лише те, що містить ці слова |
| `STOP_WORDS` | що викидати |
| `POLL_SECONDS` | як часто зазирати в канали |
| `MIN_LENGTH` | коротші пости без картинки ігноруються |
| `WATCH_EDITS` | стежити, чи канал не виправив уже надіслану новину |
| `EDIT_HOURS` | скільки годин після надсилання стежити за постом |
| `EDIT_NOTE_CHARS`, `EDIT_NOTE_RATIO` | де межа між виправленням і одруком |

Після правки файлу програму треба перезапустити.

## Де воно живе

Новинар працює **на GitHub**, не на комп'ютері: репозиторій
`knebosky-boop/novynar`, розклад — кожні 10 хвилин. Комп'ютер вимикати можна,
новини йтимуть далі.

* Подивитись, як минув останній обхід: вкладка **Actions** у репозиторії.
* Токен бота і телеграм-номер власниці лежать у Settings → Secrets, у самому
  репозиторії їх немає.
* Пам'ять (позиції каналів, читачі, дублі) зберігається між запусками
  у сховищі GitHub Actions.

⚠️ Канали, додані командою `/add`, живуть у тій пам'яті. Якщо GitHub колись
почистить сховище, список повернеться до того, що записано в `config.py`.
Тому канал, який потрібен назавжди, краще дописати ще й у `config.py`
(і залити зміну: `git add -A && git commit -m "новий канал" && git push`).

## Запуск і зупинка

На GitHub нічого запускати не треба — розклад працює сам. Зупинити:
вкладка Actions → «Новинар» → «Disable workflow».

Локально (якщо колись знадобиться) — подвійний клік на `start.command`
або в терміналі:

```
cd ~/.claude/Новинар
.venv/bin/python novynar.py
```

Щоб працювало саме, без відкритого вікна:

```
cp ua.novynar.plist ~/Library/LaunchAgents/
launchctl load   ~/Library/LaunchAgents/ua.novynar.plist   # увімкнути назавжди
launchctl unload ~/Library/LaunchAgents/ua.novynar.plist   # вимкнути
```

## Файли

| Файл | Що це |
|---|---|
| `config.py` | усі налаштування |
| `novynar.py` | сама програма |
| `novynar.db` | пам'ять: канали, читачі, дублі, черга |
| `novynar.log` | журнал: що надіслано, що відсіяно і чому |
| `novynar_account.py` | запасний варіант — читання через ваш акаунт (для закритих каналів) |

## Межі

* Закриті канали цим способом не читаються — лише відкриті.
* Затримка до 10 хвилин: GitHub будить програму за розкладом, а не тримає
  її ввімкненою постійно. Команди боту (`/add`, `/status`) теж виконуються
  не миттєво, а під час найближчого обходу.
* Відео не пересилається файлом — іде обкладинка, текст і посилання на оригінал.
* Виправлення каналу ловляться, лише поки пост видно на сторінці `t.me/s/канал`
  (останні ~20 постів). У найбалакучішого каналу це близько години.
* Новини з нічного зведення виправленню не підлягають: там вони йдуть
  спільним списком, а не окремими повідомленнями.
* Telegram дозволяє боту правити свої повідомлення 48 годин — далі виправлення
  прийде окремим повідомленням.
